# 连线类解谜游戏调研

更新日期：2026-09-04

## 结论先行

如果目标不只是复刻，而是做一款有鲜明交互手感的数字连线游戏，优先试玩下面 12 种。

| 优先级 | 游戏 | 核心机制 | 值得研究的原因 | 数字化表现机会 |
| --- | --- | --- | --- | --- |
| S | [Mid-loop / 中环](https://cn.gridpuzzle.com/mid-loop) | 提示点必须是所在直线段的严格中点 | 一条局部规则同时约束方向和长度，推理非常“几何” | 拖线时两端镜像生长；长度不平衡时产生弹性阻力 |
| S | [Masyu / 珍珠](https://cn.gridpuzzle.com/masyu) | 白珠直行且邻格转弯；黑珠转弯且邻格直行 | 规则少、图形语言强、局部推理链丰富 | 珍珠被正确“穿线”或“包角”时可给出明确咬合反馈 |
| S | [Yajilin / 箭头回路](https://puzz.link/p?yajilin) | 箭头统计黑格；剩余格组成单环 | “画线”和“放障碍”互相制约，状态变化丰富 | 黑格落下后挤压路线，路径可表现为绕障碍收紧 |
| S | [Slalom](https://puzz.link/p?slalom) | 单环依次穿过编号门，过门时必须直行 | 同时具备路径、顺序、方向三类约束 | 过门、错序、逆向都能形成自然的机械反馈 |
| S | [Icebarn](https://puzz.link/p?icebarn/10/9/trhatb5os111t7l5tnbzbzzwrzxlz7/3/16) | 路径在冰区不能转弯，冰上允许正交交叉 | “惯性”规则天然符合物理直觉 | 拖入冰区后自动滑行；非法转向可表现为侧向打滑和回弹 |
| S | [Kuroshiro](https://gridpuzzle.com/kuroshiro) | 相邻同色圆之间不转弯，异色圆之间恰好转一次 | 约束作用在“两个提示之间”，形成节奏感 | 路段可随两端颜色显示张力；转弯次数可即时可视化 |
| A | [Rail Pool](https://www.gmpuzzles.com/blog/2022/12/rail-pool-by-martin-ender/) | 覆盖所有格；区域提示给出穿过该区的直线段长度集合 | 把全局 Hamilton 环和局部长度集合结合，逻辑密度高 | 直线段转弯后结算长度，适合做伸缩轨道动画 |
| A | [Moon or Sun](https://www.janko.at/Raetsel/Moonsun/) | 每区选月或日，区域选择沿环交替 | 路线选择同时决定区域状态，主题表达自然 | 进入区域时切换昼夜状态，错误选择能沿路径传播提示 |
| A | [Castle Wall](https://puzz.link/p?castle) | 白色城堡在环内、黑色城堡在环外，箭头统计远处线段 | “环的内外”成为可操作信息，空间感强 | 闭合前后区域填色；错误包围关系可用城墙压力反馈 |
| A | [Numberlink](https://www.gmpuzzles.com/blog/2025/05/numberlink-by-grant-fikes-2/) / [Flow Free](https://www.bigduckgames.com/flowfree) | 配对端点，路径不重叠；Flow Free 还要求铺满盘面 | 最低理解门槛，最适合大众移动端 | 拖线、覆盖、抢占空间、断线重连都能做出直接反馈 |
| A | [Hashi / 数桥](https://zh.puzzle-bridges.com/) | 岛屿度数、直桥、最多双桥、全网连通 | 从“路径”扩展到“网络”，推理维度明显不同 | 单桥到双桥的并轨、拉索张力、孤立网络告警 |
| A | [Pipelink](https://cn.gridpuzzle.com/pipelink) / [Net](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/js/net.html) | 全格管线或旋转管件，最终形成一个连通结构 | 机械结构最直观，适合强调拼接、通电和流动 | 接头吸附、管线通流、错误泄漏、局部网络逐段点亮 |

## 纸笔谜题机制库

### 一、配对与多路径

| 游戏 | 核心规则 | 主要乐趣 | 备注 |
| --- | --- | --- | --- |
| [Numberlink](https://www.gmpuzzles.com/blog/tag/numberlink/) | 将相同数字两两连接，路径不交叉、不重叠，常见版本要求覆盖全部格子 | 多条路径争夺有限空间 | 原型门槛最低，但题目生成要防止靠猜测 |
| [Flow Free](https://www.bigduckgames.com/flowfree) | 连接全部同色端点并覆盖全盘，管线不能交叉 | 颜色直观，短局爽快 | Bridges、Warps、Hexes、Shapes 都是成熟扩展方向 |
| Link-a-Pix / PathPix | 相同数字成对连接，数字等于路径长度，完成后显出像素画 | 解题结果同时是一幅图 | 适合关卡收藏和主题化内容 |
| [Kouchoku](https://puzz.link/p?kouchoku) | 用任意角度直线连接所有点形成一个环；同符号点需连续出现 | 非正交几何和交叉关系 | 视觉辨识度高，但触屏命中和遮挡需要专门设计 |
| [Angle Loop](https://madmahoganypuzzles.wordpress.com/2020/12/16/puzzle-24-angle-loop/) | 用直线连接所有符号成环；三角、方形、五边形分别表示锐角、直角、钝角 | 用角度而不是格距推理 | 很适合做节点吸附和角度刻度反馈 |
| [Ichimaga](https://en.gridpuzzle.com/rule/ichimaga) | 所有圆点连成一个网络；数字是节点度数；两点间最多转一次 | 路径规划与图论连通性结合 | 与 Hashi 相似，但 L 形连接带来更大的空间博弈 |

### 二、沿格线画环

| 游戏 | 核心规则 | 主要乐趣 | 备注 |
| --- | --- | --- | --- |
| [Slitherlink / 数回](https://www.puzzle-loop.com/) | 沿格线画单环，格内数字表示四周被使用的边数 | 局部计数会产生连续推导 | 最经典、题源多、规则教学容易 |
| [Mejilink](https://www.janko.at/Raetsel/Mejirinku/index.htm) | 沿区域已有边画单环；每个区域未被环使用的边数等于区域面积 | 形状、周长和环路同时作用 | 像 Slitherlink，但提示来自整个异形区域 |
| Corral / Bag | 数字格必须在环内；数字表示横竖方向在碰到环前可见的格数 | 从内部“看见”边界 | 环完成时形成清晰的内外区域 |
| Vertex Slitherlink | 提示位于顶点，统计周围若干边或转角 | 熟悉规则的视角转换 | 适合作为 Slitherlink 的中后期变体 |
| Konarupu / 转角数回 | 格内数字表示四个顶点上环路转弯的次数 | 推理对象从“边数”变为“拐角数” | [在线试玩](https://cn.gridpuzzle.com/konarupu) |
| [Gokigen Naname / Slant](https://gridpuzzle.com/slant/vneey) | 每格放一条对角线，顶点数字为接入线数，且所有线不能成环 | 极简二选一操作与全局无环约束 | 严格说目标是“禁止成环”，但很值得作为反向机制参考 |

### 三、沿格心画单环

| 游戏 | 核心规则 | 主要乐趣 | 备注 |
| --- | --- | --- | --- |
| [Masyu](https://cn.gridpuzzle.com/masyu) | 白珠直行且前后至少一处转弯；黑珠处转弯且前后都直行 | 转弯与直行的局部组合 | 最适合建立统一的“线段状态机” |
| [Mid-loop](https://cn.gridpuzzle.com/mid-loop) | 点必须是直线段中点，且不能在点上转弯 | 对称长度推理 | 极适合做双向同步生长 |
| [Balance Loop](https://cn.gridpuzzle.com/balance-loop) | 白圈两侧直臂等长，黑圈两侧不等长；数字给出两臂长度和 | 比 Mid-loop 更开放的长度比较 | 可把“平衡/失衡”直接做成视觉反馈 |
| [Geradeweg / 直线环路](https://cn.gridpuzzle.com/straight-loop) | 数字表示穿过提示格的直线段长度；若在提示格转弯，两臂都为该长度 | 精确控制直线段尺寸 | 与轨道伸缩、标尺动画很契合 |
| Shingoki / Traffic Lights | 黑圈转弯、白圈直行，数字约束两侧直线段总长 | Masyu 与长度提示的混合 | [Puzz.link 题型表](https://puzz.link/list.html)中可试玩 |
| [Kuroshiro](https://gridpuzzle.com/kuroshiro) | 连续两个同色圆之间不转弯，异色圆之间恰好转一次 | 提示之间的关系推理 | 很适合做“路段节奏”主题 |
| [Dotchi-Loop](https://cn.gridpuzzle.com/dotchiloop) | 经过所有白圈、避开黑圈；同一区域内白圈统一全部直行或全部转弯 | 一次判断影响整个区域 | 区域状态切换具有强传播感 |
| [Yajilin](https://puzz.link/p?yajilin) | 箭头数字统计方向上的黑格；黑格不相邻；其余可用格组成单环 | 涂黑和画环双系统互锁 | 信息密度高，适合进阶产品 |
| [Tapa-Like Loop](https://puzz.link/p?tapaloop) | 提示描述周围八格中被环访问的连续组长度 | 环路版 Tapa，局部模式丰富 | 需要良好的候选标记交互 |
| [Castle Wall](https://puzz.link/p?castle) | 提示格不可经过；白提示在环内、黑提示在环外；箭头数字统计指定方向被环穿过的边界数 | 内外关系和远距统计 | 适合城墙、领地等具象主题 |
| [Country Road](https://logic-puzzles-online.com/zh-hant/country-road/) | 环恰好访问每个区域一次；数字为区域内经过格数；跨区域边界的相邻两格不能同时为空 | 把区域当作只有一进一出的“元格” | 区域较少时也能产生很深的全局推理 |
| [Moon or Sun](https://www.janko.at/Raetsel/Moonsun/) | 每区只经过全部月亮或全部太阳，且相邻访问区域的选择必须交替 | 路线和二元区域状态同步确定 | 主题、关卡叙事和状态动画都很自然 |
| Onsen-meguri | 环恰好访问每个区域一次；数字表示环在该区域内的转弯次数 | 以区域为单位计算路线形态 | 可在 [Puzz.link 题型表](https://puzz.link/list.html)中搜索试玩 |
| [Double Back](https://zh.gridpuzzle.com/doubleback) | 环经过所有白格；每个区域恰好被访问两次 | 全覆盖与区域出入次数结合 | 边界穿越计数是主要推理抓手 |
| [Slalom](https://puzz.link/p?slalom) | 从起点成环，所有门恰好直穿一次，并按编号顺序经过 | 顺序、方向和拓扑同时约束 | 最容易包装成运动或竞速主题 |
| [Icebarn](https://puzz.link/p?icebarn) | 从入口到出口；经过全部箭头和冰区；冰上直行且可交叉 | 惯性与定向路线 | 少数天然适合做物理运动感的纸笔谜题 |
| [Pipelink](https://cn.gridpuzzle.com/pipelink) | 单环覆盖全部格并使用预置管段；允许正交自交，但交叉处不能转弯 | 填满、交叉和预置形状 | 和管道、线路板主题高度一致 |
| Simple Loop / Pure Loop | 单环恰好经过每个白格一次，避开黑格 | 最纯粹的 Hamilton 环 | 规则极简，难度主要来自黑格布局 |
| [Rail Pool](https://www.gmpuzzles.com/blog/2022/12/rail-pool-by-martin-ender/) | 单环覆盖全部格；每区提示列出穿过该区的全部直线段长度种类 | 区域集合约束和全覆盖 | 适合高难关卡，不适合最初教学 |
| Maxi Loop | 单环覆盖全部白格；区域数字表示该区内最长连续路段的格数 | 在区域内比较路段长度 | [Best of 2021 Loop/Path](https://www.gmpuzzles.com/images/puzzles2021/2021-BestLoops.pdf) 有代表题 |

### 四、单路径、顺序与轨道

| 游戏 | 核心规则 | 主要乐趣 | 备注 |
| --- | --- | --- | --- |
| [Zip](https://www.gmpuzzles.com/blog/2025/03/introducing-zip/) | 从 1 开始覆盖所有格，按升序经过数字，避开墙 | Numberlink 的单线、顺序、全覆盖版本 | 规则非常适合每日短局 |
| Hidato | 用相邻格补齐连续数字，可允许八方向移动 | 在锚点之间压缩路径空间 | 数字序列直观，但更接近填数 |
| Numbrix | 与 Hidato 类似，但只允许上下左右相邻 | 更强的走廊和奇偶约束 | 适合窄长路径的视觉表达 |
| Snake | 找出一条固定长度、不能自接触的蛇，行列或局部数字给出占格数 | 路径形状与非接触约束 | 可做成实体蛇身逐节生长 |
| Train Tracks | 从入口铺到出口，轨道不交叉；行列数字给出轨道占格数 | Nonogram 式统计与路径连续性结合 | 行列完成时可做轨道锁定反馈 |

### 五、连通网络与旋转管线

| 游戏 | 核心规则 | 主要乐趣 | 备注 |
| --- | --- | --- | --- |
| [Hashi / 数桥](https://zh.puzzle-bridges.com/) | 岛屿间横竖连桥，数字是桥数，最多双桥，桥不交叉，最终全连通 | 度数约束与全局连通性 | 双桥升级动作很适合触控 |
| [Ichimaga](https://en.gridpuzzle.com/rule/ichimaga) | 数字限制节点连接数，两点间路径最多一个直角弯，最终全连通 | 自由路径和固定度数结合 | 可加入允许交叉、同数不直连等变体 |
| [Net / Pipes](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/js/net.html) | 旋转固定管件，使所有接口成为一个无环连通网络 | 每次旋转都会传播连通状态 | 最适合做“逐段通电/通水”的即时反馈 |
| Infinity Loop | 旋转线块，使所有接口闭合且没有悬空端 | 操作极简、视觉舒缓 | 通常弱化唯一连通要求，更偏休闲 |
| Loops of Zen | 旋转六角或方格管件，消除所有断口 | 图案完成感强 | 可研究柔和动画和无文字教学 |

## 商业数字游戏参考

这些作品不一定是传统纸笔谜题，但很适合研究如何把“线”变成有质感的数字对象。

| 游戏 | 主要交互 | 可借鉴点 |
| --- | --- | --- |
| The Witness | 在面板上画一条满足符号规则的路径 | 同一套拖线操作承载大量规则；环境教学几乎不用文字 |
| LYNE | 连接同类图形并覆盖指定节点 | 极简拖线、路径交叠节点、完成时的图形节奏 |
| [Railbound](https://store.steampowered.com/app/1967510/Railbound/) | 摆放、交换轨道，让多节车厢按顺序汇合 | 轨道真实连接、车辆时序验证、失败原因可见 |
| Cosmic Express | 一笔规划列车线路，按容量接送乘客 | 路线、顺序和容量约束结合 |
| Trainyard | 画轨道并合并、分离、染色列车 | 画线后运行模拟，验证阶段反馈极强 |
| klocki | 移动或旋转拼块，让线纹无缝接合 | 接缝吸附、线条连续生长、极少 UI |
| Pipe Push Paradise | 推动管件搭出可用管路 | 管件的实体阻挡、朝向和接口关系严格一致 |
| Freshly Frosted | 铺设传送带完成甜甜圈生产流程 | 路径兼具物流模拟和链式动画 |
| Please Fix The Road | 用有限操作修复道路 | 路面拼合、施工动画和操作次序 |
| Linkito | 操作机械与电路元件完成连通 | 电路通断、元件联动和机械反馈 |

## 最值得组合的原创方向

1. **Mid-loop + Slalom**
   路径按顺序过门，同时每个门必须位于一段直轨的中点。规则仍然短，但“顺序”和“对称长度”会产生新的交叉约束。

2. **Masyu + 物理轨道**
   白珠是直通轴承，黑珠是转向齿轮。玩家拖动柔性轨道，合法时吸附咬合，非法时出现方向阻力和轻微回弹。

3. **Yajilin + 动态障碍**
   玩家放下黑格后，周围路径空间即时收缩；已经画出的非法路线被挤压但不直接删除，给玩家明确的因果反馈。

4. **Moon or Sun + 区域状态传播**
   线进入房间后选择昼或夜，沿路线交替点亮。局部改线会让后续区域状态像多米诺一样翻转。

5. **Icebarn + Kuroshiro**
   冰面提供直行惯性，黑白节点决定两个节点之间的转弯次数。非常适合做“滑轨经过信号站”的具象系统。

6. **Hashi + 可伸缩机械桥**
   岛屿数字是接口容量；桥梁从岛边缘伸出并吸附，第二次拖动形成并轨。网络断开时，孤立部分降低亮度而不弹窗打断。

## 交互层面的共同经验

- 把“已确定不走”作为一等操作。高难回路题里，X 标记和画线同样重要。
- 拖动时实时预演约束，不要等松手后才报错。方向、长度、交叉、度数都可以在拖动过程中表达。
- 非法操作应保留因果：阻力、震动、局部变色或短暂回弹，比直接吞掉输入更容易理解。
- 线段、节点、轨道、管件之间要有明确的包覆与连接层级，避免视觉上连接但逻辑上未连接。
- 自动吸附必须可预测。吸附半径、方向锁定和撤销手势要始终一致。
- 完成反馈应沿实际连通结构传播，例如通电、通水、列车运行或路径逐段点亮，而不是只弹出一个通关面板。
