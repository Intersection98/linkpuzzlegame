# 连线解谜游戏大全：章节与 100 关规划

## 一、产品目标

制作一款以“画线、连通、回路”为核心的解谜游戏合集：

- 共 12 章、100 道固定关卡。
- 除第 68 关珍珠终局使用 `8x8` 外，其余关卡盘面最大为 `7x7`；后期难度仍优先通过提示密度和规则组合提升。
- 移动端优先，同时完整兼容桌面端。
- 每章对应一种独立规则，但复用一致的画线、擦除、标记、撤销和提示体验。
- 难度从直观的颜色配对，逐步过渡到单环、网络连通、转弯和线段长度的复合推理。
- 所有关卡必须唯一解，并可通过逻辑推导完成，不依赖试错枚举。
- 教学直接发生在盘面上。每章第一关为引导关，也计入 100 关。

## 三、全局难度曲线

### 1. 难度阶段

| 阶段 | 关卡 | 定位 | 目标体验 |
| --- | --- | --- | --- |
| 入门 | 1-18 | 配对与定长路径 | 先建立拖线、回退和全盘覆盖直觉 |
| 初级 | 19-44 | 沿格线单环 | 学会正向画线与反向排除，并理解“不能提前闭环” |
| 中级 | 45-68 | 填充、网络与珍珠 | 同时处理局部数字和全局连通性 |
| 高级 | 69-84 | 中点与平衡 | 从路径形状进入线段长度关系推理 |
| 专家 | 85-100 | 精确长度与复合提示 | 综合处理方向、转弯、长度和单环 |

### 2. 每章内部节奏

每章原则上使用以下节奏，关卡较少时合并中间阶段：

1. **引导关**：只出现一种新规则，盘面上直接演示一次正确操作。
2. **确认关**：取消强制引导，验证玩家是否理解核心规则。
3. **组合关**：加入该玩法的第二种局部推理。
4. **扩盘关**：扩大盘面，但不立即叠加新规则。
5. **链式关**：一次判断连续触发多步推导。
6. **全局关**：必须使用单环、全覆盖或全连通约束。
7. **综合关**：混合本章全部知识。
8. **章节终局**：盘面最大、提示更稀疏，但仍保证纯逻辑可解。

### 3. 难度控制变量

难度不能只靠扩大盘面。每关应综合控制：

- 盘面尺寸。
- 路径、颜色、节点或区域数量。
- 提示密度和提示位置。
- 最长必要推导链长度。
- 是否需要全局连通、奇偶、提前闭环等判断。
- 同时存在的候选分支数量。
- 玩家在不试错的情况下找到下一步的难度。

章节内不允许连续两关同时显著增加盘面和规则复杂度。新规则出现后的下一关应保持同尺寸，让玩家先巩固。

## 四、章节详案

## 第一章：Numberlink 数连

**关卡：1-10，共 10 关**

### 正式规则

- 盘面包含若干对相同颜色的端点。
- 从一个端点画线，连接到唯一的同色端点。
- 路径只能在上下左右相邻格之间移动。
- 不同路径不能交叉、重叠或分叉。
- 每个端点只能作为路径的起点或终点。
- **所有格子都必须被某条路径覆盖。**
- 不使用数字区分端点；除颜色外同时使用纹理或符号，避免仅靠颜色识别。

### 章节教学重点

- 从端点按住并拖动即可画线。
- 反向拖回已经经过的格子，可以自然收线。
- 拖入另一条路径时，当前线产生阻力并停在冲突前，不直接覆盖旧线。
- 两端连接但仍有空格时，只显示“尚未铺满”，不误判通关。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 1 | 4x4，2 色 | 引导拖线；路径短且互不干扰 |
| 2 | 4x4，3 色 | 独立完成；第一次要求铺满全盘 |
| 3-4 | 5x5，3-4 色 | 引入绕行和边缘通道 |
| 5-6 | 6x6，4-5 色 | 引入路径争夺中心、先后顺序和狭窄通道 |
| 7 | 6x6，4 色 | 降低提示密度；长路径必须绕过中心并回收边角 |
| 8 | 7x7，5 色 | 外圈与内圈相互制约，错误连接会延迟暴露 |
| 9 | 7x7，5 色 | 多层嵌套路径；需要连续使用封闭区域判断 |
| 10 | 7x7，5 色 | 极限终局；稀疏端点、长路径套叠与全盘剩余空间推理 |

## 第二章：NumberEnd 定长数连

**关卡：11-18，共 8 关**

这是本项目对 Numberlink 的定长变体，规则口径必须固定。

### 正式规则

- 相同数字各出现两次，它们是同一条路径的两个端点。
- 相同数字必须通过上下左右相邻格连接。
- 数字 `N` 表示这条路径必须恰好占用 `N` 个格子。
- **长度计数包含两个数字端点。** 例如，两个 `4` 之间的路径总共占 4 格，中间有 2 个非端点格。
- 不同路径不能交叉、重叠或分叉。
- 每个数字只能作为路径端点，不能被其他路径穿过。
- 所有格子都必须被恰好一条路径覆盖。
- 首发关卡只使用 `2-9`；不使用需要特殊解释的单格数字 `1`。

### 章节教学重点

- 拖线时在路径旁实时显示 `当前长度 / 目标长度`。
- 达到目标长度后，线头出现明确止挡；继续拖动时只产生轻微拉伸和回弹。
- 未到目标就碰到同数端点时不自动完成，并显示缺少的格数。
- 超长、接错数字、占用其他路径格子是三种不同错误，反馈不能混用。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 11 | 4x4，2 对数字 | 引导长度计数，目标长度差异明显 |
| 12-13 | 5x5，3-4 对数字 | 精确绕行；短路径限制长路径 |
| 14-16 | 6x6，4-5 对数字 | 多条路径共同分割全盘 |
| 17 | 7x7，5-6 对数字 | 相同端点距离接近但目标长度不同 |
| 18 | 7x7，6 对数字 | 综合终局；需要同时利用长度与剩余面积 |

## 第三章：Slitherlink 数回

**关卡：19-28，共 10 关**

### 正式规则

- 沿网格点之间的横边或竖边画线。
- 所有线段最终必须组成一条封闭的单环。
- 环不能交叉、分叉，也不能出现多条独立小环。
- 格内数字 `0-3` 表示该格四条边中恰好有多少条属于环。
- 没有数字的格子不提供局部边数约束。
- 每个网格点最终连接 0 条或 2 条线。

### 章节教学重点

- 首次引入“线”和“排除标记 X”两种边状态。
- 移动端提供线模式与 X 模式；桌面端左键画线、右键标 X。
- 已满足的数字显示绿色；超出数字时显示红色，但保留玩家画出的线段。
- 允许暂时闭合局部环；最终通关时所有线段必须组成唯一单环。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 19 | 4x4 | 教学 `0` 和顶点 0/2 度 |
| 20 | 4x4 | 教学角落 `3` 和排除标记 |
| 21-23 | 5x5 | 加入 `1`、`2`，训练单格边计数 |
| 24-26 | 6x6 | 相邻 `3`、`3-0`、对角传播 |
| 27 | 6x6 | 提示稀疏，主要依赖长链和单环约束 |
| 28 | 7x7 | 综合终局；通过稀疏提示与长距离连通提升难度 |

## 第四章：Mejilink 区域回路

**关卡：29-36，共 8 关**

### 正式规则

- 盘面由边界线围成若干区域，区域可由一个或多个格子组成。
- 只能沿区域边界画线；同一区域内部的格线不可画。
- 所有画出的线必须组成一条不交叉、不分叉的单环。
- 对每个封闭区域，**未被环使用的边数必须等于该区域的面积格数**；开放到棋盘外的区域不参与计数。
- 同一条边如果同时属于两个区域的边界，对两个区域分别参与计算。

### 章节教学重点

- 区域内不显示数字；边数满足面积条件时，整个区域点亮为绿色。
- 选中区域时仅高亮其周界，避免玩家误把面积理解为周长。
- 画线与 X 标记沿用 Slitherlink 的操作，不重新教学基础手势。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 29 | 5x5 | 单格区域，建立“未用边 = 面积”概念 |
| 30 | 5x5 | 加入双格区域，比较面积与周长 |
| 31-33 | 6x6 | L 形、长条形区域和共享边联动 |
| 34-35 | 7x7 | 区域形状复杂，提示传播距离增加 |
| 36 | 7x7 | 综合终局；必须结合区域计数和单环约束 |

## 第五章：Pipelink 管道回路

**关卡：37-44，共 8 关**

### 正式规则

- 在格子中心之间画出一条连续管道。
- 管道必须经过所有可用格子；黑格不属于盘面。
- 题目预置的直管、弯管或交叉管段必须原样保留和使用。
- 管道可以在格内正交交叉；交叉处两条路径都必须直行，不能转弯。
- 管道不能重叠，最终必须构成一条连续闭合路线。
- 除交叉格会被正交经过两次外，其余可用格恰好经过一次。

### 章节教学重点

- 拖过格子时，管道形状根据进入和离开方向自然生成。
- 预置管段像固定轨道，不允许被拖动改形。
- 第一次引入交叉格时使用分步动画，明确“相交但不连通”。
- 路线经过所有格后才允许闭合完成。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 37 | 4x4 | 预置弯管；教学全格单回路 |
| 38 | 4x4 | 教学固定交叉，明确两条管道互不连通 |
| 39 | 5x5 | 横直管与竖直管共同限制路径方向 |
| 40-41 | 6x6 | 弯管联动，并开始要求推断未标出的交叉格 |
| 42 | 6x6 | 多个固定交叉形成长距离连通约束 |
| 43 | 7x7 | 固定交叉与候选交叉位置共同牵制 |
| 44 | 7x7 | 稀疏管件终局；必须结合全覆盖和单回路推理 |

## 第六章：Thermometers 温度计

**关卡：45-52，共 8 关**

本章不是单环，而是利用管线方向进行连续填充，用于缓冲前后章节并训练顺序约束。

### 正式规则

- 盘面由若干互不重叠的温度计组成，每支都有圆形球部和末端。
- 每支温度计可以为空、部分填充或完全填充。
- 液体必须从球部开始连续填向末端，中间不能留空。
- 盘面外的行列数字表示该行或该列恰好有多少个填充格。
- 所有行列数字都必须同时满足。

### 章节教学重点

- 从球部向外拖动可连续填充；反向拖动可降低液面。
- 填充远端格时，靠近球部的前置格自动同步填充。
- 将某格标为空时，它之后靠近末端的格子自动标为空。
- 桌面与移动端都支持点击格子在“未知、填充、排除”之间切换。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 45 | 4x4 | 教学连续填充，使用单向直温度计 |
| 46-48 | 5x5-6x6 | 仅使用直温度计，逐步加入横纵混合分区 |
| 49 | 6x6 | 首次引入转弯温度计 |
| 50-51 | 7x7 | 稀疏计数与长折管的上下界传播 |
| 52 | 7x7 | 综合终局；连续多次行列传播 |

## 第七章：Hashi 数桥

**关卡：53-60，共 8 关**

### 正式规则

- 数字圆点是岛屿，只能与同一行或同一列中视线可达的最近岛屿连接。
- 两座岛之间可以有 0、1 或 2 座桥。
- 岛屿数字表示与该岛相连的桥梁总数。
- 桥不能穿过岛屿，也不能与其他桥交叉。
- 最终所有岛屿必须属于同一个连通网络。

### 章节教学重点

- 点击两座相邻岛屿之间的航道：第一次建立单桥，第二次升级双桥，第三次清除。
- 桥梁必须从岛边缘伸出并与目标岛边缘咬合，不能只在视觉上接近。
- 已满足数字的岛屿进入稳定状态，但仍允许玩家撤销连接。
- 数字全部满足但网络分裂时，高亮孤立网络而不是直接判错。

| 55 | 6x6，11 岛 | 高数字连续传播 |
| 56 | 6x6，13 岛 | 首次引入交叉航道排除 |

## 第八章：Masyu 珍珠

**关卡：61-68，共 8 关**

### 正式规则

- 在格子中心之间画出一条不交叉、不分叉的单环。
- 环必须经过所有黑色和白色珍珠，但不必经过所有空格。
- 白珍珠处必须直行，并且沿路径紧邻白珍珠的前一格或后一格至少有一格转弯。
- 黑珍珠处必须转弯，并且沿路径紧邻黑珍珠的前后两格都必须直行。
- 不能在全部珍珠被纳入前形成独立小环。

### 章节教学重点

- 先用纯白珠和纯黑珠小盘分别建立两条局部规则，再进入黑白混合推理。
- 依次引入边界限制、相邻黑珠互斥、连续三白珠垂直穿越和提前闭环排除。
- 后三关减少提示密度，要求通过珍珠间的长距离传播和全局单环约束收束答案。
- 每关均由求解器验证为唯一解；终局关扩展为 8x8，其余关卡最大为 7x7。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 61 | 4x4 | 白珠入门；仅白珍珠，利用边界确定直穿方向 |
| 62 | 5x5 | 黑珠转角；仅黑珍珠，掌握转弯后两侧延伸 |
| 63 | 5x5 | 黑白牵引；相邻异色珍珠连续传播方向 |
| 64 | 6x6 | 相邻黑珠；利用黑珠之间不能直接相连进行排除 |
| 65 | 6x6 | 三白成列；连续白珠强制垂直穿越 |
| 66 | 6x6 | 回路取舍；结合局部规则避免提前闭合 |
| 67 | 7x7 | 稀珠长链；低提示密度下进行跨区域推理 |
| 68 | 8x8 | 珍珠终局；连续白珠、黑珠夹击、远距联动与全局单环互锁 |

## 第九章：Mid-loop 中环

**关卡：69-76，共 8 关**

### 正式规则

- 在格子中心之间画出一条不交叉、不分叉的单环。
- 环必须经过所有提示点，但不必经过所有格子。
- 提示点可能位于格子中心，也可能位于两个格子的边界中点。
- 环经过提示点时必须直行。
- 提示点必须是该直线段的严格中点：从提示点向两侧延伸到第一次转弯的距离完全相等。

### 章节教学重点

- 从提示点向一侧拖动时，另一侧以镜像方式预览等长延伸。
- 一侧被边界或已有路径阻挡时，另一侧的最大长度同步受限。
- 未达到对称条件时，提示点显示为未平衡，不立即报错。
- 同尺寸关卡不得通过旋转或镜像复用提示布局与答案环。
- 所有关卡必须通过唯一解校验，终局重点使用防小环和长链牵制。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 69 | 3x3 | 四个格心点组成最小单环，只教学中点与直行 |
| 70 | 5x5 | 稀疏错位点阵，加入相邻点和防小环判断 |
| 71 | 6x6 | 密集边中点双向折返，练习局部长度锁定 |

## 第十章：Balance Loop 平衡环

**关卡：77-84，共 8 关**

### 正式规则

- 在格子中心之间画出一条不交叉、不分叉的单环。
- 环必须经过所有圆圈，但不必经过所有格子。
- 圆圈处可以直行，也可以转弯。
- 从圆圈沿环向两个方向观察，分别量到第一次转弯为止，得到两条直臂长度。
- 白圈表示两条直臂等长。
- 黑圈表示两条直臂不等长。
- 圆圈内若有数字，该数字等于两条直臂长度之和。

### 章节教学重点

- 选中圆圈时，单独高亮它的两条直臂，避免把整段环误认为计数对象。
- 白圈使用平衡反馈；黑圈两臂暂时等长时只提示“尚未满足”，不直接判死。
- 有数字的圆圈实时显示当前两臂长度和。

### 关卡安排

| 关卡 | 盘面建议 | 内容 |
| --- | --- | --- |
| 77 | 4x4 | 等臂初识；密集无数字白圈，只教学两臂等长 |
| 78 | 5x5 | 白圈折臂；减少提示，辨认圆圈处直行与转弯的共同计数方式 |
| 79 | 5x5 | 黑圈失衡；首次加入无数字黑圈，用不等长排除对称走法 |
| 80 | 5x5 | 黑白牵制；同一局部同时受到等长与不等长约束 |
| 81 | 6x6 | 长度刻度；仅白色数字圈，利用偶数总长直接平分两臂 |
| 82 | 6x6 | 奇偶拆分；加入黑色奇数圈，在 `1+2`、`1+4` 等组合间联动排除 |
| 83 | 7x7 | 数字交锁；全数字黑白圈沿边界和中心长距离互锁 |
| 84 | 7x7 | 平衡终局；数字与无数字圈混合，必须结合局部长度和全局单环定解 |

## 第十一章：Geradeweg 直线环路

**关卡：85-92，共 8 关**

### 正式规则

- 在格子中心之间画出一条不交叉、不分叉的单环。
- 环必须经过所有数字圆圈，但不必经过所有格子。
- 数字表示与该圆圈关联的直线长度，以相邻格心之间的线段数计。
- 若环直行经过圆圈，从前一次转弯到后一次转弯的整条直线段长度等于数字。
- 若环在圆圈处转弯，连接在该圆圈上的两条直线段长度都分别等于数字。

### 章节教学重点

- 首次明确区分“直穿数字”和“在数字处转弯”的两种计数方式。
- 拖动到转弯处时结算直线段长度，并沿整段显示短暂刻度。
- 多个相同数字可以位于同一条直线段上，不能把数字误当作线段终点。

## 第十二章：Shingoki 交通灯

**关卡：93-100，共 8 关**

### 正式规则

- 在格子中心之间画出一条不交叉、不分叉的单环。
- 环必须经过所有交通灯圆圈，但不必经过所有格子。
- 白色圆圈处必须直行。
- 黑色圆圈处必须转弯。
- 灰色圆圈可以直行或转弯，需要由其他条件确定。
- 圆圈内数字表示从该圆圈向环的两个方向延伸出的直线段长度之和。
- 两侧直线段都在首次转弯处结束；同一直线上的其他圆圈不会截断计数。

### 章节教学重点

- 颜色负责形状，数字负责长度，两类条件必须分层显示。
- 白灯使用直行导轨反馈；黑灯使用转向咬合反馈；灰灯在确定前保持中性。
- 实时显示两个方向的长度拆分，例如 `2 + 3 = 5`。
- 第 100 关不增加新规则，只综合此前全部推理。

## 五、跨端交互规范

### 1. 共通操作

| 行为 | 移动端 | 桌面端 |
| --- | --- | --- |
| 画线 | 单指按住并拖动 | 左键按住并拖动 |
| 收线 | 沿原路径反向拖动 | 沿原路径反向拖动 |
| 单步切换 | 点击目标边或格 | 左键点击 |
| 排除标记 X | 切换到 X 模式后拖动或点击 | 右键拖动或点击 |
| 撤销/重做 | 底部图标按钮 | 图标按钮，支持 `Ctrl/Cmd+Z` 与 `Ctrl/Cmd+Shift+Z` |
| 取消当前拖动 | 手指移出棋盘后松开 | `Esc` 或移出棋盘后松开 |
| 缩放 | 无需缩放，棋盘完整适配视口 | 无需缩放，棋盘完整适配视口 |

### 2. 响应式布局

- 手机竖屏：棋盘在上，底部固定工具栏；关卡信息保持一行，不挤占棋盘高度。
- 手机横屏和平板：棋盘居中，工具栏放在右侧或底部。
- 桌面端：棋盘居中，章节与关卡信息位于左侧，操作工具位于右侧。
- 棋盘不得因提示文本、计数变化、完成动画而改变尺寸或跳动。
- 除第 68 关为 `8x8` 外，其余关卡不超过 `7x7`；所有棋盘均需在移动端无需页面缩放即可完成。
- 细线目标使用扩大后的透明命中区域，但命中区域不能跨过相邻边的中线。
- 所有关键状态不能只依赖颜色；同时使用形状、纹理、明暗或符号。
- 不依赖 hover 才能发现功能；桌面 hover 仅补充 tooltip。
- 适配手机安全区，底部工具栏不能被系统手势区域遮挡。

### 3. 手感与反馈

- 合法连接：线头吸附到节点、边或相邻格中心，吸附过程不改变逻辑落点。
- 非法方向：线头表现出短距离弹性阻力，松手后回到最后合法位置。
- 超出长度：允许少量视觉拉伸，但逻辑线段不进入非法格。
- 路径冲突：冲突双方短暂强调，不能只把新输入静默丢弃。
- 完成局部提示：数字、圆圈或岛屿降低对比度，不播放打断操作的弹窗。
- 全局完成：反馈沿真实路径或网络传播，最后再显示通关操作。
- 震动只用于明确的吸附、止挡和通关；桌面端用音效与微动效替代。
- 动画只表现逻辑结果，不允许出现视觉上已连接但判定尚未连接的中间状态。

## 六、关卡数据与验收标准

### 1. 每关最少数据

```text
id
chapterId
type
width
height
clues
givens
solution
difficultyScore
tutorialSteps
expectedTechniques
parTime
```

### 2. 关卡验收

每关进入正式版本前必须满足：

- 存在解，且只有一个解。
- 求解器在不使用随机猜测的逻辑模式下可完成。
- 记录关键推理链，能够为提示系统提供“为什么是这一步”。
- 不存在开局只能任选分支、最后靠碰运气排除的情况。
- 首次出现的新技巧只在一个局部位置发生，避免教学信息竞争。
- 同章相邻关卡的难度分不能出现无意的大幅回落或跳升。
- 至少由两名未参与出题的测试者完成。
- 手机 360x800、390x844、平板 768x1024、桌面 1440x900 下均可操作。
- 棋盘、提示、工具栏和系统安全区之间无重叠。
- 色觉模拟、键鼠操作和触屏操作都能独立完成关卡。

### 3. 难度评分建议

内部使用统一分值，不直接展示给玩家：

```text
difficultyScore =
  forcedStepCount * 1
  + longestDeductionChain * 3
  + globalConstraintUses * 5
  + simultaneousCandidates * 2
  + boardComplexity
```

评分仅用于初排。最终顺序以真实玩家的首通时间、撤销次数、提示使用率和卡点分布校正。

## 七、内容制作顺序

1. 先实现通用棋盘、输入、撤销、重做、提示和完成检测。
2. 优先制作第 1、3、8 章，验证“格路径、格边回路、格心回路”三类基础引擎。
3. 再实现第 2、4、5、7 章，补齐长度、区域、交叉和网络能力。
4. 最后实现第 6、9、10、11、12 章的顺序填充与线段测量系统。
5. 每个玩法先完成 2 道教学样关和求解器，再批量生产正式关卡。
6. 100 关全部通过唯一解、纯逻辑、跨端可操作和难度曲线验收后再锁定编号。
